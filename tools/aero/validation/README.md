# Validation fixtures

Generated by `python -m tools.aero.validate --dump`.

Each file is one named throw: the disc, the throw parameters, the
environment, the integrator settings, a summary, and the full
per-sample trajectory (position, velocity, disc normal, quaternion,
spin, angle of attack and the three coefficients actually used).

Track B should reproduce these with `DiscFlightSim` using the same
baked table from `game/data/aero/`. Sampling is every 12 substeps at
dt = 1/240, i.e. 20 Hz.

Sign conventions are CONTRACT §1. Note that `hyzer_angle_rad` is
positive-is-left-bank for a RHBH throw, following CONTRACT §5
(a right bank turns right); the parenthetical in §4 says the
opposite and is believed to be an editorial slip.
